# KDP Coloring Book Studio (Amazon KDP Interior PDF Generator)

Автоматизированный инструмент для создания интерьерных файлов PDF для детских раскрасок под публикацию на **Amazon KDP**.

---

## 🚀 Быстрый запуск в 1 клик

### Вариант 1: Графический веб-интерфейс (Рекомендуется)
Просто дважды кликните по файлу **`run_ui.bat`**.
- Откроется браузер по адресу `http://localhost:8000`
- **Единый двухвкладочный интерфейс**:
  - **Вкладка «Внутренний блок (Interior)»**: подготовка страниц, удаление рамок ChatGPT, отбеливание фона, визуальный просмотр разворотов и генерация Interior PDF.
  - **Вкладка «Обложка книги (Cover PDF)»**: сборка полного разворота обложки (Back + Spine + Front) для Amazon KDP с 4 миниатюрами в аккуратных двойных рамках (вертикально отцентрированных), авторасчетом корешка, логотипом бренда и предпросмотром по кнопке.

### Структура папки книги (исходники):
- `cover_front.png` (или `.jpg`) — передняя обложка
- `cover_back.png` (или `.jpg`) — задняя обложка
- `001.png`, `002.png`... — страницы внутреннего блока (файлы `cover_*` автоматически исключаются из обработки интерьера)

### Вариант 2: Запуск через консоль (CLI)
Дважды кликните по файлу **`run_cli.bat`** (или выполните команду в консоли):
```bash
python -m src.cli -i "reference/FarmAdventures" -f a4
```

### Вариант 3: Удаление рамок у сгенерированных картинок (ChatGPT Frame Remover)
- **В веб-интерфейсе (`run_ui.bat`)**: специальная карточка с кнопкой **«Удалить рамки с картинок»** прямо на панели управления.
- **Через консоль / батник**: дважды кликните по файлу **`crop_borders.bat`** (или перетащите на него папку):
```bash
python crop_borders.py -i "reference/FarmAdventures"
```
Скрипт автоматически распознает одинарные и двойные рамки любой толщины, вырезает область строго внутри рамки и масштабирует рисунок до 100% исходного размера. По умолчанию перезаписывает файлы на месте (in-place) без отладочных оверлеев. При необходимости отдельной папки передайте флаг `-o <путь>` (или `--debug` для превью).

### Вариант 4: Очистка фона картинок (ChatGPT Cleaner)
Дважды кликните по файлу **`clean_images.bat`** (или используйте кнопку «Очистка фона» в веб-интерфейсе).
Скрипт переведёт весь околобелый фон в чистый `#FFFFFF`, сохранив контуры рисунка насыщенно чёрными, и сохранит результат в папку `cleaned/`.

## 🎨 Оформление и поля Amazon KDP

- **Поля (Safe Zone)**:
  - **Корешок (Gutter)**: **20 мм** со стороны переплёта.
  - На всех иллюстрациях и титуле (правые страницы) корешок находится **слева**.
  - На странице 2 (копирайт, левая страница) корешок находится **справа**.
  - Верх, низ и внешний край: **15 мм**.
- **Двойная векторная рамка (начиная со страницы 3)**:
  - Две тонкие линии толщиной **1.5 pt**.
  - Расстояние между линиями: **3.0 мм**.
  - Иллюстрация вписывается вплотную во внутреннюю рамку без отступов.
  - Страницы 1 и 2 масштабируются с безопасными полями, но без линий рамки.
- **Очистка фона ChatGPT**:
  - Динамическая эмуляция уровней Photoshop: отсекает шум и серый фон (215–254) в идеальный белый 255.

| Формат | Размеры (мм / дюймы) | Точки PDF (72 pt) | Разрешение при 300 DPI |
|---|---|---|---|
| **A4 Portrait** | 210 × 297 мм (8.27 × 11.69") | 595.28 × 841.89 pt | 2480 × 3508 px |
| **8.5 × 8.5" Square** | 215.9 × 215.9 мм (8.5 × 8.5") | 612.00 × 612.00 pt | 2550 × 2550 px |
